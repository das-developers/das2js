Catalog browser

Walk the das federated catalog. Each level is fetched when it is opened; das2C picks the child, falls back to the next mirror, and builds request URLs for data sources. A blank seed starts at das2C's compiled in root and opens site:/uiowa. A Collection or SourceSet is shown as the one source das2C can use in it; the rare one holding several opens as a folder when clicked.

Using the internal test catalog: a partial copy in test/catalog/. Branches outside it will fail; data requests still go to the live servers.
