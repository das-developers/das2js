Tests

Each reports pass or fail on the page, and in the terminal too when run under make server.

Performance Simultaneously fetch and render a live stream. Tests network, parse and render times. Provides stats for a quick test and a half GB browser hammer. Module test Run the module against builtin streams, no network required. Produces the same page as make headless_test. Fetch only A real request an online dasFlex server or to as local sibling next door when served with RUNFLAGS=--dasflex. Same page as make live_test.

Tools

Catalog browser Walk the das federated catalog a level at a time and turn a data source's examples into request URLs. Stream inspector Load any stream URL and see every dataset, dimension and variable as JSON, without the data values. ?url=... bookmarks a stream.
